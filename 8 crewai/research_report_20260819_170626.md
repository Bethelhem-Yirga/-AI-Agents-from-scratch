### Code Example: Analyzing the Beauty Industry in Ethiopia
The following Python code example demonstrates how to analyze sales data for local beauty products.

```python
# Import necessary libraries
import pandas as pd
import matplotlib.pyplot as plt

# Sample Data: Beauty Product Sales in Ethiopia
data = {
    'Product': ['Shea Butter', 'Ethiopian Coffee Scrub', 'Natural Hair Oil', 'Herbal Face Wash', 'Organic Lip Balm'],
    'Sales_Q1': [1500, 1200, 1800, 900, 1100],
    'Sales_Q2': [1600, 1300, 2000, 950, 1150],
    'Sales_Q3': [1700, 1400, 2200, 1000, 1200],
    'Sales_Q4': [1800, 1500, 2500, 1100, 1250],
}

# Create DataFrame
df = pd.DataFrame(data)

# Calculate total annual sales
df['Total_Sales'] = df[['Sales_Q1', 'Sales_Q2', 'Sales_Q3', 'Sales_Q4']].sum(axis=1)

# Print the DataFrame with total sales
print("Beauty Products Sales Data:")
print(df)

# Plotting the sales data
plt.figure(figsize=(10, 6))
plt.bar(df['Product'], df['Total_Sales'], color='skyblue')
plt.title('Total Annual Sales of Beauty Products in Ethiopia')
plt.xlabel('Beauty Products')
plt.ylabel('Total Sales')
plt.xticks(rotation=45)
plt.grid(axis='y')
plt.show()
```

### Explanation of Key Implementation Details
- **Data Representation**: Sales data for various beauty products over four quarters is represented in a dictionary format.
- **Pandas DataFrame**: The dictionary is transformed into a DataFrame for analysis.
- **Total Sales Calculation**: A new column calculates total sales across all quarters.
- **Data Visualization**: A bar chart visualizes total sales to reveal market trends.
